# Spooderman

A janky little 3D web-swinging game. Pre-alpha. Art is placeholder on purpose.

**Play:** open `index.html` in a browser (phone or PC). Needs internet once to load three.js from a CDN.

## Controls

| | Phone | PC |
|---|---|---|
| Move | drag on left side of screen | WASD |
| Look | drag anywhere else | mouse |
| Left web | hold left half of the on-screen mouse | hold left click |
| Right web | hold right half of the on-screen mouse | hold right click |
| Jump / wall jump | JUMP button | Space |

- Let go of a web to fling yourself forward.
- Run into a wall to climb it.
- Collect the 12 pink `?` cubes on the rooftops. There is no ending yet.
